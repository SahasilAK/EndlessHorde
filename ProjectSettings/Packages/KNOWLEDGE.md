# Packages/

Per-package editor settings persisted by Unity.

## Subfolders
- `com.unity.ai.assistant/` — AI Assistant preferences. See [`com.unity.ai.assistant/KNOWLEDGE.md`](com.unity.ai.assistant/KNOWLEDGE.md).
- `com.unity.learn.iet-framework/` — Learn/tutorial framework preferences. See [`com.unity.learn.iet-framework/KNOWLEDGE.md`](com.unity.learn.iet-framework/KNOWLEDGE.md).
- `com.unity.probuilder/` — ProBuilder editor preferences. See [`com.unity.probuilder/KNOWLEDGE.md`](com.unity.probuilder/KNOWLEDGE.md).
