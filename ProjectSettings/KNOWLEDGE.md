# ProjectSettings/

Unity project-wide player, editor, input, physics, graphics, and build configuration.

## Subfolders
- `Packages/` — persisted settings for installed editor packages. See [`Packages/KNOWLEDGE.md`](Packages/KNOWLEDGE.md).

## Files
### `ProjectVersion.txt`
Pins Unity Editor version `6000.6.3f1`.

### `ProjectSettings.asset`
Project identity, player, resolution, and platform build settings.

### `EditorBuildSettings.asset`
Scenes and options included in player builds.

### `EditorSettings.asset`
Editor serialization, asset pipeline, and version-control preferences.

### `VersionControlSettings.asset`
Unity version-control integration settings.

### `PackageManagerSettings.asset`
Package Manager configuration.

### `AudioManager.asset`
Global audio mixer and playback settings.

### `InputManager.asset`
Legacy input configuration retained alongside the Input System package.

### `DynamicsManager.asset`
3D physics defaults.

### `Physics2DSettings.asset`
2D physics simulation and collision settings.

### `PhysicsCoreProjectSettings2D.asset`
Core 2D physics project defaults.

### `GraphicsSettings.asset`
Graphics pipeline and shader configuration.

### `QualitySettings.asset`
Named rendering quality levels.

### `TimeManager.asset`
Fixed timestep and time-scaling defaults.

### `TagManager.asset`
Project tags, layers, and sorting layers.

### `NavMeshAreas.asset`
Navigation mesh area definitions.

### `NetworkManager.asset`
Networking project defaults.

### `MultiplayerManager.asset`
Multiplayer services configuration.

### `ClusterInputManager.asset`
Cluster-display input configuration.

### `MemorySettings.asset`
Runtime memory and allocator settings.

### `PresetManager.asset`
Editor preset assignment rules.

### `SceneTemplateSettings.json`
Editor settings for scene templates.

### `ShaderGraphSettings.asset`
Shader Graph editor and generation settings.

### `URPProjectSettings.asset`
Universal Render Pipeline project settings.

### `VFXManager.asset`
Visual Effect Graph project defaults.

### `XRSettings.asset`
XR support and loader settings.

### `UnityConnectSettings.asset`
Unity Services project connection settings.

### `ProjectAuditorSettings.asset`
Unity Project Auditor configuration.
