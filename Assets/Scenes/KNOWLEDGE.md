# Scenes/

Unity scenes for the playable game and the original template.

## Files
### `Game.unity`
Main gameplay scene containing the retro player and tiled ground, spawner, HUD, menus, cameras, audio wiring, and an EventSystem with the Input System UI module for button clicks.

### `SampleScene.unity`
Unmodified or template sample scene; the game build uses `Game.unity`.
