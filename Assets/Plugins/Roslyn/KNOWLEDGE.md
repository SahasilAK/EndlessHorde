# Roslyn/

Managed compiler assemblies used by editor tooling to compile C# code dynamically.

## Files
### `Microsoft.CodeAnalysis.dll`
Roslyn compiler platform assembly.

### `Microsoft.CodeAnalysis.CSharp.dll`
C# language compiler implementation for Roslyn.

### `System.Collections.Immutable.dll`
Immutable collection dependency used by Roslyn.

### `System.Reflection.Metadata.dll`
Metadata reader/writer dependency used by Roslyn.

### `System.Runtime.CompilerServices.Unsafe.dll`
Low-level runtime support dependency used by Roslyn.
