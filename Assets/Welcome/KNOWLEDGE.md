# Welcome/

Unity 2D template welcome-page assets retained from project creation.

## Files
### `Welcome2DScript.cs`
`Welcome2DScript` is a template ScriptableObject with an editor action that opens Unity's 2D landing page.

### `Welcome2DScript.asset`
Serialized welcome-page ScriptableObject instance.

### `NewWelcomePage.asset`
Template welcome-page content asset.

### `TutorialProjectSettings.asset`
Settings asset used by the template's tutorial/welcome flow.

### `Welcome2DScript.asmdef`
Assembly definition for the template welcome-page script.

### `2d-template.png`
Template image displayed by Unity's 2D welcome flow.
