# Fonts & Materials/

TextMesh Pro font assets and material presets used for rendering UI text.

## Files
### `LiberationSans SDF.asset`
Default SDF font asset referenced by `TMP Settings.asset`.

### `LiberationSans SDF - Fallback.asset`
Fallback font asset for glyphs missing from the default font.

### `LiberationSans SDF - Outline.mat`
Outline material preset for the Liberation Sans SDF font.

### `LiberationSans SDF - Drop Shadow.mat`
Drop-shadow material preset for the Liberation Sans SDF font.
