# Resources/

Runtime-loadable TextMesh Pro defaults and text layout resources.

## Subfolders
- `Fonts & Materials/` — default font asset and material presets. See [`Fonts & Materials/KNOWLEDGE.md`](<Fonts & Materials/KNOWLEDGE.md>).
- `Style Sheets/` — default TMP rich-text styles. See [`Style Sheets/KNOWLEDGE.md`](<Style Sheets/KNOWLEDGE.md>).

## Files
### `TMP Settings.asset`
TMP runtime settings, including the default Liberation Sans SDF font and sprite asset.

### `LineBreaking Leading Characters.txt`
Characters that cannot begin a wrapped line.

### `LineBreaking Following Characters.txt`
Characters that cannot end a wrapped line.
