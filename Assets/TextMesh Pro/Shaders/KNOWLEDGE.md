# Shaders/

TextMesh Pro rendering shaders and shared shader includes bundled with TMP Essentials.

## Files
- `TMP_Bitmap.shader`, `TMP_Bitmap-Mobile.shader`, `TMP_Bitmap-Custom-Atlas.shader` — bitmap text variants.
- `TMP_SDF.shader`, `TMP_SDF SSD.shader`, `TMP_SDF Overlay.shader`, `TMP_SDF SpaceWarp.shader` — desktop SDF variants.
- `TMP_SDF-Mobile.shader`, `TMP_SDF-Mobile-2-Pass.shader`, `TMP_SDF-Mobile Masking.shader`, `TMP_SDF-Mobile Overlay.shader`, `TMP_SDF-Mobile SSD.shader`, `TMP_SDF-Mobile SSD SpaceWarp.shader`, `TMP_SDF-Mobile SpaceWarp.shader` — mobile SDF variants.
- `TMP_SDF-Surface.shader`, `TMP_SDF-Surface-Mobile.shader` — surface-lit variants.
- `TMP_SDF-URP Lit.shadergraph`, `TMP_SDF-URP Unlit.shadergraph`, `TMP_SDF-HDRP LIT.shadergraph`, `TMP_SDF-HDRP UNLIT.shadergraph` — render-pipeline shader graphs.
- `TMP_Sprite.shader` — TMP sprite rendering.
- `SDFFunctions.hlsl`, `TMPro.cginc`, `TMPro_Mobile.cginc`, `TMPro_Properties.cginc`, `TMPro_Surface.cginc` — shared shader functions and properties.
