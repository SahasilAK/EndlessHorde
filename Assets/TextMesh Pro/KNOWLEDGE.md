# TextMesh Pro/

Unity's bundled TextMesh Pro Essentials resources required for the game's TMP-based HUD and menus.

## Subfolders
- `Fonts/` — Liberation Sans source font and license. See [`Fonts/KNOWLEDGE.md`](Fonts/KNOWLEDGE.md).
- `Resources/` — TMP runtime defaults, font materials, and style sheet. See [`Resources/KNOWLEDGE.md`](Resources/KNOWLEDGE.md).
- `Shaders/` — TMP text and sprite rendering shaders. See [`Shaders/KNOWLEDGE.md`](Shaders/KNOWLEDGE.md).
