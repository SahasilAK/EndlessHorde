# Settings/

Input and Universal Render Pipeline assets used by the 2D game.

## Subfolders
- `Scenes/` — URP 2D scene template. See [`Scenes/KNOWLEDGE.md`](Scenes/KNOWLEDGE.md).

## Files
### `DefaultVolumeProfile.asset`
Default URP volume profile for post-processing.

### `InputSystem_Actions.inputactions`
Input System action definitions generated with the project template.

### `Lit2DSceneTemplate.scenetemplate`
Unity scene template configuration for a 2D lighting scene.

### `Renderer2D.asset`
2D renderer configuration used by the URP asset.

### `UniversalRP.asset`
Universal Render Pipeline asset configured for the project.

### `UniversalRenderPipelineGlobalSettings.asset`
Global URP settings shared by the editor and player.
